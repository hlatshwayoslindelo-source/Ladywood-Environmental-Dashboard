Ladywood Streamlit fixed package

Upload these files to the main page of your GitHub repo:
- environmental_dashboard.py
- requirements.txt

Also make sure your data files are on the main GitHub repo page:
- brownfield.xlsx
- air_quality_2026.csv
- surface_water_flooding.json
- rainfall.csv

After upload:
1. Click Commit changes on GitHub.
2. Go to Streamlit.
3. Open Manage app.
4. Click Reboot app.
5. Refresh the page.
